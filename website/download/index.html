System requirements

  • Operating system: macOS 14 Sonoma or later, including Sequoia 15 and Tahoe 26.
  • Processor: Apple silicon or Intel.
  • Download: approximately 5 MB; the exact size can change by release.
  • Permission: Accessibility is optional for automatic pasting. Without it, select a clip and paste manually with Command + V.

The latest release link always opens the current GitHub release. Version 0.0.26 was current when this page was reviewed on July 27, 2026.

Install in about two minutes

  1. Download the latest DMG. Open the latest release above and select the Clipboard History disk image under Assets.
  2. Open the disk image. Double-click the downloaded DMG in your Downloads folder.
  3. Move the app to Applications. Drag Clipboard History into the Applications folder.
  4. Launch Clipboard History. Open it from Applications. It runs in the menu bar and does not keep a Dock icon.
  5. Try the shortcut. Copy some text, then press Shift + Command + V. Select the item and press Return.

If macOS asks for Accessibility access, grant it only if you want the app to paste the selected item automatically. You can decline and use Command + V manually. Read why the permission is requested before deciding.

What you get

  • Searchable history for copied text, links, files, and folders.
  • A customizable global shortcut, with Shift + Command + V as the default.
  • Favorites and groups for reusable clips.
  • A history limit from 100 to 10,000 items, with 1,000 as the default.
  • Local-only storage, a pause control, and application exclusions.
  • Automatic checks for signed updates through Sparkle.

Check these limits before downloading

No cloud sync: history stays on the Mac where it was captured. It will not appear automatically on another Mac, iPhone, or iPad.

No raw clipboard images: images and screenshots copied directly as bitmap data are not currently recorded. Image files copied in Finder are supported, along with other files and whole folders. Read the files and image-format guide.

Tahoe already has a basic option: macOS 26 can search Clipboard history through Spotlight. If that covers your needs, you may not need another app. Our macOS clipboard-history guide explains how to use it and when a dedicated manager helps.

Verify before you install

The source code, issue history, release notes, and update feed are public. Downloads are distributed through the project's GitHub Releases page, and app updates are cryptographically verified before installation.
