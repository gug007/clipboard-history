Finder clipboard workflow

Clipboard history for files and folders on Mac.

Copy a file in Finder once, find it later by name, and paste it again as a real file. Clipboard History keeps a reference and small preview—not another full copy.

Files & foldersSaved by referenceSearchable filenames

Yes, copied Finder items are supported

Clipboard History records files and folders copied in Finder. Press Shift + Command + V, search by filename, select the item, and press Return to paste it into the current destination.

The app saves the location of the original item and a small preview. It does not put the entire file into its SQLite history database. A large video, archive, or project folder therefore does not become a second full-sized copy inside the app.

How to retrieve a file you copied earlier

  1. Copy in Finder. Select one or more files or folders and press Command + C.
  2. Continue working. Copy other text, links, or Finder items as needed; the earlier item remains in history.
  3. Open Clipboard History. Press Shift + Command + V from Finder or another app.
  4. Search by name. Type part of the file or folder name and use the arrow keys to select it.
  5. Paste or reveal. Press Return to paste, or Command + R to show the original item in Finder.

You can star a file reference with Command + D or place it in a group if it is part of a recurring workflow. Review all available actions in the keyboard shortcut guide.

How each copied format is handled

What you copySupported?How it is handled
File copied in FinderYesOriginal location plus a small preview
Folder copied in FinderYesOriginal location plus a small preview
Image file copied in FinderYesHandled as a file reference
Several Finder itemsYesRecorded as copied file references
Direct PNG or TIFF image, including a clipboard screenshotYesImage payload plus a bounded preview thumbnail
RTF or HTML rich textYesOriginal rich format plus a searchable plain-text fallback

Two image paths: a PNG copied in Finder is stored as a reference to that file. A screenshot sent directly to the clipboard, or a PNG/TIFF image copied inside a browser or editor, is stored as bounded clipboard image data. Clipboard History does not run OCR, recognize QR codes, or search inside the pixels.

A reference is not a backup

Because the app points back to the original file or folder, that original still matters. If it is deleted, disconnected on an external drive, or moved somewhere the stored reference can no longer resolve, Clipboard History cannot recreate the file from its preview.

Use a backup system for recovery and Clipboard History for faster reuse. Starred file references also do not freeze a version of a document; they continue to point to the item on disk.

References and previews remain local to this Mac. Clipboard History has no account and no cloud synchronization. Read the security model for storage and access details.

Where file history saves time

  • Attaching documents: retrieve the PDF or image you copied earlier without reopening its folder.
  • Organizing projects: copy several source files, then paste them into destinations in a different order.
  • Reusing assets: star frequently used logos, templates, or reference folders.
  • Finding the source: use Command + R when you remember the filename but not its original folder.
